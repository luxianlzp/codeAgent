# single-html

Use this skill when working in the `examples/demo2` project.

## Instructions

- Complete the project with a single HTML file.
- Put all HTML, CSS, and JavaScript in that one `.html` file.
- Do not create separate `.css`, `.js`, asset, build, package, or framework files unless the user explicitly asks for them.
- Prefer editing the existing `index.html` when it exists.
- Keep the result runnable by opening the HTML file directly in a browser.
- After changes, verify the final file still contains the full page structure, styles, and scripts in one place.
